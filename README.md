# コルツセンター強盗 回収補助ツール

GitHub Pagesで動く、サーバー不要の静的Webアプリです。

## 主な機能

- 2F / 1F / B1 / 金庫室のマップ切り替え
- 固定湧き地点へのターゲット種別・金額入力
- ボーナス対象（黄色ドルマーク）の指定
- ブラウザーへの自動保存
- URLだけで入力内容を共有
- 参加人数ごとの最高額回収パターン計算
- 中型のバッグ消費を20% / 25%から切り替え

## GitHub Pagesへの公開

1. GitHubで新しい公開リポジトリを作る
2. このフォルダー内のファイルをすべてアップロードする
3. リポジトリの `Settings` → `Pages`
4. `Deploy from a branch` を選択
5. Branchを `main`、フォルダーを `/(root)` にして保存

数分後、表示されたURLから利用できます。

## 注意

マーカー座標は提供画像をもとに初期設定しています。位置がずれている地点は `app.js` の `FLOORS` 内にある百分率座標を修正してください。
