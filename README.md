# コルツセンター強盗 回収補助ツール v12

GitHub Pagesでそのまま公開できる静的Webツールです。

## 地点種類の設定

地点ごとの種類は `config.js` の `SPOT_TYPES` だけで管理します。

```js
'1f-01': 'small',
'2f-01': 'painting'
```

使用可能な値:

- `painting`
- `medium`
- `small`
- `reinforced`
- `main`（メインターゲット専用）

現在は仮設定として、1Fをすべて `small`、それ以外の通常地点をすべて `painting` にしています。

## 公開

ファイル一式をGitHubリポジトリのルートへ配置し、GitHub Pagesを `main` / `(root)` で有効化してください。

## v14: 共有リンクの短縮

共有データは、JSON全文ではなく固定された地点順を使ったコンパクトなバイナリ形式で保存します。
変更のない地点や地点IDをURLへ含めないため、入力数にもよりますが従来より大幅に短くなります。
v13以前に発行した旧形式の共有リンクも引き続き読み込めます。
